# Bill Splitter

Split group expenses and see who pays whom (Gujarati and English).

**Website (works on phone and PC, no install):** https://1darshankumarsavsani-blip.github.io/Bill-Splitter/

## Downloads (latest release)

- `Bill_Splitter.apk`: Android app (works offline, the whole app is inside).
- `Bill_Splitter_Windows.exe`: Windows launcher (opens the website in its own window; Edge or Chrome needed).
